# Complaint Management System (CMS)

## Project Overview
The Complaint Management System is a web-based application developed to manage and resolve user complaints efficiently. The system allows users to submit grievances online and track their status, while administrators can review and manage the complaints through an admin panel.

## Features
- User registration and login
- Complaint submission by users
- Complaint status tracking
- Admin dashboard for managing complaints
- Responsive user interface using Bootstrap
- Database integration for storing complaint records

## Technologies Used
- HTML
- CSS
- Bootstrap
- JSP
- Java
- MySQL

## Project Structure
- Frontend: HTML, CSS, Bootstrap
- Backend: JSP and Java
- Database: MySQL

## How to Run the Project
1. Install and configure Apache Tomcat server.
2. Set up MySQL database.
3. Import the project into your IDE (Eclipse or IntelliJ).
4. Configure database connection in the project.
5. Deploy the project on the Tomcat server.
6. Open the application in the browser.
